# non_truth_checker｜非真值命题可信度校验器

版本：v1.0

一句话简介：一套面向不存在唯一客观真值的假说的工程化可信度评估脚手架，不判定真假，只评估置信度与证据链，给出可证伪的测试方案。

## 1. 项目简介

绝大多数事实核查工具、批判性思维提示词，都默认一个前提：命题存在唯一标准答案，目标是输出「真 / 假 / 存疑」。
但我们大量高价值思考，落在没有标准答案的灰色地带：前沿技术猜想、社科解释框架、个人适配判断、无权威定论的舆论推论、主观选择类假说。

本框架放弃二元真假判决，把可信度从「结论自带属性」转为过程与证据链的属性，通过多条弱信号叠加，量化评估假说置信度，强制标注不确定性、识别思维陷阱，并给出对抗测试方案。
它不是真理机器，是用来抵抗证实偏误、同源回声、指标异化的思考脚手架。

核心底层思路：
不再问「这个结论是不是真的」，而是问「产出这个结论的过程是否可靠、可检验」。

## 2. 与同类框架的核心差异

市面上事实核查框架（ClaimEval / ECE / 各类事实核查 Agent）：
预设存在真值，目标判定 claim 真假；遇到开放假说容易强行站队、抹除不确定性。
论证图、QBAF：逻辑精细，但偏重形式化，学习成本高，缺少概率校准、对抗复测、Goodhart 风险审查。
普通批判性思维提示词、红队脚本：只覆盖单一环节（交叉验证、找反例），没有闭环流水线。

✅ 本框架独有设计：

1. 前置分支开关：先判断命题是否存在唯一真值；有真值交给检索核查 / Lean 形式证明，无真值才启动本流水线
2. 固定闭环 5 步：溯源 → 独立冗余校验 → 历史战绩 & Brier 校准 → 可证伪对抗测试 → 显式不确定性检查
3. 强制内置 Goodhart 风险审查：评估当前打分指标会不会被选择性采样、刷分、样本分布污染
4. 对照形式证明范式（Lean），清晰标注弱证据叠加方案的边界
5. 输出导向行动：不止给出置信等级，附带可落地的复测、证伪方案

对比一句话
传统事实核查：寻找证据，判断结论是否为真
non_truth_checker：没有标准答案时，审查证据生成过程，评估我们应当对这个假说持有多大置信度，以及下一步如何设计实验证伪它

## 3. 适用范围 & 禁止使用范围

✅ 适合输入

- 前沿技术猜想（梯度对齐能否精细调控商用模型边界等）
- 社科 / 心理学解释框架（价值观分层模型等）
- 个人适配、发展选择假说（某方向是否适合自己）
- 仅有零散口述、没有权威定论的事件推论
- 无法拿到唯一裁判的开放性推断

❌ 不适合输入

- 存在唯一客观真值、可检索核验的事实（日期、官方通报、理化参数、定论史实）
- 可形式化证明的数理命题（这类优先 Lean 等形式验证）
- 纯粹主观审美、无讨论价值的个人感受
- 有明确权威结论的法律、规范条文

## 4. 核心校验流水线（5 步）

1. **溯源校验**
追溯断言原始信源层级；区分一手原始材料、二次转述、多手网传；记录转述链路长度、明确信息缺口。输出：溯源是否可追踪、缺口位置。
2. **独立冗余校验**
区分佐证是否来自互相独立的信源；同源复述、互相抄录的回声不增加可信度，只有互不依赖的证据收敛才加分。输出：冗余支撑强度、同源污染风险。
3. **历史战绩 & 概率校准（Brier Score 思路）**
考察该信源 / 框架长期命中率，检验它给出的置信概率是否匹配真实结果；区分单次个案和长期统计样本。输出：是否具备校准条件、样本充足度。
4. **可证伪与对抗测试**
构造反例、变换条件、重复复测，观察结论稳定性；给出推翻该假说的明确判定条件。输出：可证伪强弱、不稳定风险点。
5. **显式表达不确定性检查**
检验表述是否主动标出边界、未知信息、适用前提；区分笃定结论和带边界的假说。输出：是否隐藏不确定性。

附加强制环节：**Goodhart 风险审查**
思考：本次校验用到的评估指标，会不会被选择性采样、人为优化、刷分，从而失效？

参照对照：**Lean 形式验证**
Lean：编译通过 = 真值落地，一次性判决；
本框架：没有单一裁判，依靠多条弱信号叠加，持续更新置信度。

## 5. 输出规范

每次校验固定输出 5 块内容：

1. 分项定性结论：5 个校验环节各自的支撑点、缺陷
2. 综合置信等级：高可信假说 / 中等可信假说 / 低可信假说
3. Goodhart 风险提醒：指标异化、证实偏误等潜在陷阱
4. Lean 对照说明：对比形式化证明的差异
5. 推荐动作：悬置判断 / 继续收集对抗实验证据 / 有限条件采信（仅高可信场景）

## 6. 调用模板（直接复制给大模型）

```plaintext
你现在启用 non_truth_checker 非真值命题可信度校验器。
前置判断：先确认这个命题是否存在唯一客观真值。
- 如果存在唯一真值：不启用本框架，直接走事实核查/形式验证；
- 如果不存在唯一真值，启动下面5步流水线：
1.溯源校验
2.独立冗余校验
3.历史战绩与Brier概率校准
4.可证伪与对抗测试
5.显式表达不确定性检查

最后必须附加：Goodhart风险审查 + Lean范式对照 + 综合置信等级 + 推荐动作。

待校验命题：
背景简述：
```

## 7. 完整示例摘要（4 个案例，可直接作为 Demo）

**Demo1：长沙民政大体老师事件，断言：涉事学生为男性 / 女性**

- 溯源：官方一级通报无性别信息；网传说法来自单一第三方口述，转述链路长
- 独立冗余：所有传闻同源，无独立交叉证据，属于回声
- 校准：口述爆料历史战绩不稳定，无概率校准
- 对抗测试：更换提问方式，结论不稳定，无法稳定复现
- 不确定性：直接下定论会掩盖信息缺口
- 综合等级：低可信假说
- 推荐动作：悬置判断，不做性别定论

**Demo2：断言：梯度对齐可以精细、可控地调节商用 C 端模型输出边界**

- 溯源：实验室论文有支撑，工业落地细节不公开
- 独立冗余：多组论文在小模型上复现，但 C 端产品难以区分梯度对齐 / 外层风控
- 校准：缺少标准化长期数据集，无法量化命中率
- 对抗测试：免费 Demo 现象无法迁移到正式 C 端产品，结论漂移
- 不确定性：不能笼统宣称商用模型已经落地成熟梯度对齐
- 综合等级：中等可信假说（仅实验室场景成立）
- 推荐动作：继续设计隔离变量的对抗测试，区分梯度微调与推理层拦截

**Demo3：断言：价值观对人的影响分为四层（单次选择、事后合理化、上游筛选、自我认同）**

- 溯源：整合自认知失调、情境主义、身份认同等心理学理论，属于人为重构的简化框架
- 独立冗余：底层观测来自多条独立研究脉络，但分层划分是主观切割
- 校准：适合回溯解释，不适合定量预测，无法 Brier 校准
- 对抗测试：包容性强，可证伪门槛偏高，容易自圆其说
- 不确定性：它是解释视角，不是客观心智结构
- 综合等级：高可信的解释工具，非客观真理
- 推荐动作：可以用来复盘分析，但不用于精准预测个体行为

**Demo4：断言：电子信息工程 + 信号处理 + AI 交叉方向适合我**

- 溯源：学科大纲、行业要求、导师资源、自我观察多源支撑
- 独立冗余：学科、思维特质、环境资源多维度佐证，但存在自相关
- 校准：仅有少量个人历史样本，无法精准概率校准
- 对抗测试：可通过实操、项目、推导练习证伪，可证伪性强
- 不确定性：兴趣只是起点，无法保证长期耐受枯燥
- 综合等级：中等偏上可信假说
- 推荐动作：开展实操验证，持续收集证据更新置信度

## 8. 风险与局限

1. GIGO（垃圾进，垃圾出）：框架不会自动识别虚假输入；使用者需要有能力区分信源、识别同源回声。
2. 以定性评估为主：Brier Score 的思路被保留，但绝大多数场景缺少长期数据集，很难做到严格量化。
3. 不能根除主观立场：使用者如果带着预设立场，刻意挑选支持证据，这套框架依然会被用来包装偏见；对抗测试要求使用者主动寻找反例。
4. 永远不会给出 100% 确定结论：适合愿意接受「悬置判断」的使用者，想要直接拿到对错答案的人会觉得它回避问题。
5. 它是思考脚手架，不是自动化决策机器人，最终置信判断依然依赖人的判断力。
