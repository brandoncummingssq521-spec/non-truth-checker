# Dify 版说明

`non-truth-checker.yml` 是一个 Dify 应用 DSL 模板（Chatflow，DSL 版本 0.1.5），结构极简：开始节点（两个输入：命题、背景）→ LLM 节点（内置 5 步校验系统提示词）→ 回复节点。

## 导入步骤

1. 打开 Dify → 工作室 → 创建应用 → 选择「导入 DSL 文件」，上传 `non-truth-checker.yml`。
2. **导入后必做一件事**：打开「可信度校验」LLM 节点，把模型换成你自己 Dify 里已经配置好的模型（模板里写的是占位模型 gpt-4o-mini，你的环境里没有这个模型就会报错）。建议选推理能力较强的模型，温度保持 0.3 左右。
3. 点预览，填入测试命题跑一遍：
   - 无真值命题：「梯度对齐可以精细可控地调节商用 C 端模型输出边界」——应走完 5 步并给出置信等级。
   - 有真值命题：「水的化学式是什么」——应被前置分流拒绝。
   两个都对，模板即配置正确。
4. 发布后可通过 Dify 的 API / WebApp 对外提供服务；上架 Dify 模板市场需由账号本人提交。

## 说明

- 模板只依赖一个 LLM 节点，不接知识库、不调外部工具，任何 Dify 实例（云端或自部署）都能导入。
- 若你的 Dify 版本较新，导入时如提示 DSL 版本升级，确认即可，节点结构不变。
