# 扣子（Coze）版说明

本目录提供两种上扣子的方式，任选其一：

## 方式 A：技能包（SKILL.md）

`SKILL.md` 是与主仓库一致的技能文件（Agent Skills 通用格式）。在支持技能导入的扣子工作台 / 编程智能体里导入本文件（或整个仓库），智能体即可按 5 步流水线执行校验。

## 方式 B：提示词 Bot（最稳，零开发）

1. 打开扣子 → 创建智能体（Bot）。
2. 把 `bot-prompt.md` 里代码块的全文，粘贴到该 Bot 的「人设与回复逻辑」。
3. 模型任选（建议选推理能力较强的模型），温度调低（0.2–0.4），有利于严格按步骤输出。
4. 开场白建议填：「把你要校验的命题发给我，最好附一句背景：为什么它没有标准答案。」
5. 发布前自测两个命题：
   - 无真值命题：「梯度对齐可以精细可控地调节商用 C 端模型输出边界」——应走完 5 步并给出置信等级。
   - 有真值命题：「水的化学式是什么」——应被前置分流拒绝，并说明走事实核查。
   两个都对，说明 Bot 配置正确。

## 上架平台市场

发布 Bot 时选择公开 / 提交到商店即可；描述可直接用仓库 README 的一句话简介。注意：上架审核与发布必须由账号本人操作。
